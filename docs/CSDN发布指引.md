## 常见问题

**Q：粘贴后代码块格式乱了？**
A：CSDN 的 Markdown 模式识别 ``` 代码块。粘贴后如果乱了，切换到「预览」标签看实际效果，或点工具栏「代码块」按钮重新框选。

**Q：表格显示不正常？**
A：CSDN 支持标准 Markdown 表格（`|---|---|` 分隔行）。若不显示，切到「预览」标签确认。

**Q：图片上传后太大/太小？**
A：插入后点图片可手动拖拽调整宽度，或在 Markdown 模式下改图片尺寸参数。

**Q：想加封面图？**
A：发布设置里有「封面」选项，可以用 `csdn-image-1-ui.png`。
